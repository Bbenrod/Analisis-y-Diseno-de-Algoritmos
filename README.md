# Análisis y Diseño de Algoritmos

Ejercicios y proyectos de **Análisis y Diseño de Algoritmos (007343)**, Universidad Autónoma de Guadalajara.

| Proyecto | Contenido |
| --- | --- |
| [DFS: componentes conexos](dfs_connected_components/) | Búsqueda en profundidad y [camino mínimo con Dijkstra](dijkstra_shortest_path/). |
| [Fibonacci matricial](fibonacci-matricial/) | Fibonacci por multiplicación matricial y exponenciación rápida. |
| [QuickSort: análisis empírico mediante Monte Carlo](quicksort-monte-carlo/) | QuickSort con pivote aleatorio, 450 mediciones, datos y gráfica comparativa. |

Cada carpeta contiene su propio código y las instrucciones necesarias para ejecutarlo. El reporte académico de QuickSort se entrega por separado y no forma parte de este repositorio.

Las implementaciones y pruebas están en [dfs_connected_components](dfs_connected_components/)
y [dijkstra_shortest_path](dijkstra_shortest_path/). Las figuras se pueden regenerar con
[`report_assets/generate_graph_figures.py`](report_assets/generate_graph_figures.py).
